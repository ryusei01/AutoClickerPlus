# AutoClickerPlus

Android 7.0（API 24）以降で動作する、タップとスクロールの自動実行アプリです。

## 機能

- タップ／スクロールを複数追加し、任意の順番に並べ替え
- 「N秒待つ」待機アクション（小数秒可、最大1時間）
- アクションごとの「次の動作までの待機時間」
- 待機時間を実行ごとに `±30ms` ランダム化
- アクションごとの位置揺らぎを `±3～10px` で指定
- STOPまで無限実行、または指定回数実行
- 番号付きドラッグマーカーによる座標指定
- 背後のアプリを操作しながら行える位置指定
- アイコン式フローティングツールバー
- フローティング画面からの追加・削除・並べ替え・全設定編集
- フロー図風のアクション一覧。詳細は開閉でき、数値はフォーカスが外れたときに保存
- 複数の名前付きスクリプトを保存・選択・複製
- 全スクリプトのJSON Export／Import
- 文字存在、UI活性状態、画面色によるAND／OR条件分岐
- THEN／ELSEのあと、指定番号のアクションへ戻る／進む
- 条件成立時などに使える「ループ終了」アクション
- スクロールの末尾で指を止めて慣性スクロールを抑える（「最後で止める」）
- 設定の自動保存

## ビルド

1. Android Studioでこのフォルダーを開きます。
2. Android SDK 35とJDK 17を用意します。
3. Gradle Sync完了後、GalaxyなどのAndroid 7.0以降の端末へ実行します。

コマンドライン環境が構成済みの場合は、次でも確認できます。

```text
./gradlew test
./gradlew assembleDebug
```

## 使い方

1. アプリを開き、「アクセシビリティ設定」を押します。
2. インストール済みアプリから「AutoClickerPlus 操作サービス」を有効にします。
3. 操作したいアプリを開き、フローティングツールバーのタップ追加／スクロール追加アイコンを押します。編集アイコンから一覧を開いて追加することもできます。
4. 編集画面は上から下へ流れるフローです。ノードをタップすると詳細が開き、数値は入力後にカーソルを外すと保存されます。「待機」を追加すると、指定した秒数だけ止めてから次へ進みます。
5. 番号付きマーカーをドラッグして「決定」を押します。
   - `1`: 1番目のタップ地点
   - `2S`: 2番目のスクロール開始地点
   - `2E`: 2番目のスクロール終了地点
6. 必要に応じて、背後のアプリをスクロールしたり画面遷移したりしながら位置を調整します。マーカーと決定バー以外の場所は背後へタッチが通り、決定バーも「↕」部分から移動できます。
7. フローティング編集画面で待機時間、位置の揺らぎ、並び順、繰り返し方法を設定します。
8. ツールバーの再生アイコンで開始し、停止アイコンで停止します。矢印アイコンで最小化、×アイコンで自動実行を停止してフローティング表示を終了できます。

終了後はアプリ本体の「操作パネルを表示」から再表示できます。

## スクリプトとExport／Import

- アプリ本体上部の「保存スクリプト」から新規作成、名前変更、複製、削除、選択ができます。
- 「全件Export」は保存済みスクリプトを1つのJSONファイルへ書き出します。
- 「Import」はJSON内のスクリプトを新しいIDで追加します。既存スクリプトは上書きしません。
- Export／Importはフローティングパネルではなく、アプリ本体から操作します。

## 条件分岐

「IFを追加」して条件を設定し、THENとELSEへタップ、スクロール、別のIF、ループ終了を追加できます。各枝の最後で「次へ」のまま進むか、フロー上の番号を指定して戻る／先へ進むかを選べます。番号はルートのアクション番号（1, 2, 3…）です。次へ進む場合も、その枝ごとの待機時間を設定できます。

- 文字存在: 表示中UIの文字、説明、ヒントを完全一致または部分一致で判定
- 活性状態: 指定文字を持つUI要素のenabled／clickableを判定
- 画面色: 指定座標のRGB色を許容差付きで判定
- 複数条件: IFごとにANDまたはORを選択
- ループ終了: この操作に到達した時点で繰り返しを終了し、残りのアクションも実行しません

画面色の取得と判定にはAndroid 11（API 30）以降が必要です。セキュア画面や対象アプリ独自描画の画面では、文字・色情報を取得できない場合があります。

スクロールのランダム化では、距離と方向を保つため開始点と終了点を同じ量だけ平行移動します。
ループは最後のアクションとその待機時間が完了してから、次の周回を開始します。
ジェスチャー送信に失敗した場合は自動実行を停止します。

## 注意

- パスワード画面など、OSや対象アプリが保護する画面では操作できない場合があります。
- 誤操作を避けるため、最初は短いアクション列と回数指定で確認してください。
- Accessibility APIは本来アクセシビリティ支援のためのAPIです。Google Playで公開する場合は、最新のAccessibility APIポリシー、申告、利用目的の要件を確認してください。
- 対象サービスの利用規約や法令に従って使用してください。
